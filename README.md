# Lung cancer risk screening

Educational Streamlit app that sorts 14 survey answers into a **lower / uncertain / higher** pattern and shows
which answers drove the result. **Not a diagnosis.**

## Run
```
uv sync
uv run python -m src.train       # compares models, writes models/model.joblib, metrics.json, MODEL_CARD.md
uv run streamlit run app.py      # http://localhost:8501
uv run pytest -q                 # 9 tests
```

## Layout
- `src/features.py` - feature list and encoding shared by training and the app (prevents train/serve mismatch)
- `src/train.py` - repeated cross-validation, model comparison, tier cut-offs, bootstrap CI, model card
- `src/explain.py` - exact per-prediction contributions for the logistic regression (equals SHAP for linear models)
- `app.py` - the Streamlit UI
- `models/` - saved model, `metrics.json`, `MODEL_CARD.md` (all regenerated by training)
- `tests/` - data/model checks and headless UI tests (`streamlit.testing.v1.AppTest`)
- `notebooks/` - original exploration

## Why three tiers
With only 38 healthy people in the data, one yes/no cut-off flags about half of them. Two cut-offs chosen from
out-of-fold scores keep ~95% of cancer cases out of "lower" and ~90% of healthy people out of "higher"; the middle
band says "cannot tell" instead of guessing. Details and caveats: `models/MODEL_CARD.md`.
