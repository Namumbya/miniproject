# Lung cancer screening, explained

An educational Streamlit app. **It does not diagnose anything and is not a medical device.**

| Page | What it is |
| --- | --- |
| Start here | What actually drives lung cancer risk and what this app is and is not |
| Guideline example (US) | One worked example: the USPSTF 2021 criteria (age 50-80, 20+ pack-years, smoke now or quit within 15 years). Criteria differ by country; the page says so and points to local sources |
| Symptom model demo | A machine-learning experiment on a small public survey, kept to show how such a model is built, evaluated and explained, including its limits |

## Honest limits
The demo model uses 276 unique survey respondents of unknown origin, 86% of whom had cancer, and has no smoking
history detail. It is cross-validated (ROC-AUC about 0.93) but not externally validated, and its score is relative
to that survey, not a real-world probability. Validated tools such as PLCOm2012 already exist and are far better
evidence. See `models/MODEL_CARD.md`.

## For people cloning this
Treat the symptom model as a **pipeline demo**, not a starting point for a clinical product. To make the ML part
more meaningful you would need a much larger, better-documented dataset with real smoking history (pack-years,
years since quitting) and verified outcomes — for example NLST or PLCO via [NCI CDAS](https://cdas.cancer.gov/)
(free application; access is not instant). Avoid random Kaggle "lung cancer" CSVs unless you can verify where
they came from; many are copies or synthetic expansions of this same survey. Keep the guideline-example page
even if you replace the demo model — that logic does not depend on the survey data.

## Run
```
uv sync
uv run python -m src.train       # compares models, writes models/model.joblib, metrics.json, MODEL_CARD.md
uv run streamlit run app.py      # http://localhost:8501
uv run pytest -q                 # 17 tests
```

## Layout
- `app.py` - navigation entrypoint; `app_pages/` - the three pages
- `src/eligibility.py` - USPSTF 2021 rule (pure function, tested at every boundary)
- `src/features.py` - feature list and encoding shared by training and the demo (prevents train/serve mismatch)
- `src/train.py` - repeated cross-validation, model comparison, tier cut-offs, bootstrap CI, model card
- `src/explain.py` - exact per-prediction contributions for the logistic regression (equals SHAP for linear models)
- `models/` - saved model, `metrics.json`, `MODEL_CARD.md` (regenerated by training)
- `tests/` - data, model, eligibility and headless UI tests (`streamlit.testing.v1.AppTest`)
- `notebooks/` - original exploration
- `.github/workflows/ci.yml` - tests and a retrain check on every push
